## 目录约定

- `posters/`：视频封面图，用于 README 缩略图或文档展示。
- `previews/`：WebP 循环预览，用于 GitHub README 内联展示。
- 根目录 MP4：完整演示视频。

## 播放方式

在 GitHub 中点击文件名可查看文件信息；下载后可使用系统播放器或支持 H.264 的浏览器播放。
