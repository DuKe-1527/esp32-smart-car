# ESP32 小车网页控制台

## 工作原理

ESP32 当前代码作为 TCP Client 连接电脑的 `8080` 端口。
浏览器不能直接创建原始 TCP 连接，因此本项目在电脑上运行一个本地桥接服务：

```text
浏览器网页  ── HTTP ──┐
NetAssist  ── TCP  ──┼── 本地桥接 8080 ── TCP ── ESP32 小车
                       └── 实时日志与状态
```

## 使用方法

1. 在 NetAssist 中停止当前的 **TCP Server**。
2. 双击本目录中的 `start.bat`，等待浏览器自动打开。
3. 小车会在 2 秒内自动重连到桥接服务。
4. 网页中按住方向按钮控制，松开自动发送 `S` 停车。
5. 如需继续使用 NetAssist，将其设置为 **TCP Client**：

```text
远程主机：127.0.0.1
远程端口：8080
```

连接后在 NetAssist 中输入对应字母即可。固件带 300 ms 指令超时保护，
因此 NetAssist 中单次发送字母适合做点动测试；连续行驶请使用网页中的按住控制。
网页只显示前进、后退、左转、右转和停车五个按钮。
同时按住两个方向键时，网页会在后台自动组合成平滑的差速转向指令。

按住键盘 `Shift` 可加速，松开后立即恢复标准速度。网页中的 `SHIFT 加速`
按钮同样需要按住；松开按钮会取消加速。

固件使用平滑 PWM 渐变：每 `20 ms` 增加 1 个 PWM 单位，达到 255
最大值后保持；松开 Shift 后每 `20 ms` 减少 2 个 PWM 单位，平滑回到标准速度。
桥接服务会自动补上换行符，并把小车回包显示在网页和 NetAssist 中。

## 指令

| 指令 | 动作 |
|---|---|
| `F` | 前进 |
| `B` | 后退 |
| `L` | 左转 |
| `R` | 右转 |
| `S` | 停车 |

网页组合键会在后台自动形成平滑差速动作：

| 同时按住 | 动作 |
|---|---|
| `W + A` | 前进同时左转 |
| `W + D` | 前进同时右转 |
| `S + A` | 后退同时左转 |
| `S + D` | 后退同时右转 |

## 注意事项

- 一个 TCP 端口只能有一个监听服务。NetAssist 的 TCP Server 和本项目桥接不能同时占用 `8080`。
- 网页默认只允许本机访问，避免同一局域网中的其他人误控制小车。
- 页面失焦、方向键释放或桥接连接断开时，会尽量发送停车指令。
- ESP32 代码里的 `serverIP` 必须保持为电脑当前局域网 IP，请替换为电脑当前的局域网 IP。
